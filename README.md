# 知识归档

更新：2026-10-25。

本仓库是管家（Grok Bot）为 J 查阅、维护和持续更新的知识档案库。把已经讨论清楚、值得长期复用的内容按主题整理，支持持续新增主题和增量更新已有档案。使用时先查下方主题索引，再按归档日期、证据版本和适用范围引用。

## 仓库使用说明

管家使用本仓库前，先阅读[知识归档工作流](WORKFLOW.md)，了解触发方式、主题模板、查阅、新增、更新、来源标注和版本维护的约定。工作流是仓库的使用说明，不属于知识主题。

## GitHub 归档与版本

公开仓库：https://github.com/SherlockGy/grokbot-knowledge-archive ，默认分支 main。

GitHub 远端是本库的权威副本；管家云端电脑上的工作副本 `/home/box/grokbot-knowledge-archive` 只是可随时重新克隆的工作区。本仓库为公开仓库，只存放 J 授权公开的知识档案与使用约定，不发布完整聊天记录，不存放凭证或私人信息。

每次归档或更新按 J 当次授权进行，同步维护索引；提交并推送后回读远端文件，核对内容与提交版本，确认无误后才报告“已归档”。
